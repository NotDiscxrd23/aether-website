Features that change everything.

Every system engineered for maximum efficiency and minimal footprint.

🎯

Silent Aim

Intercepts raycasts at the metatable level (__namecall). Zero recoil. Redirects trajectories locally.

👁️

Advanced ESP

3D Boxes, Skeletons, Tracers drawn natively using the Drawing API. Updates via RenderStepped.

📷

Camera Freeze

Locks CFrame in place while character moves. Watchdog prevents game resets.

✨

Glassmorphism UI

Custom draggable interface. Tabs, sliders, dropdowns, and TweenService animations.

🧠

Smart Caching

Caches targets every 0.1s. Filters dead players/teammates to keep CPU usage minimal.

Under the hood.

How the Lua architecture is structured. A breakdown of the script's internal modules.

Module Functionality Technical Implementation
Services & State Initializes core variables. Calls game:GetService() and builds a centralized Config table.
The Hook Redirects weapon fire. Uses getrawmetatable(game) to intercept __namecall. Filters Raycast calls.
ESP Engine Renders visual overlays. Converts 3D to 2D via WorldToViewportPoint, updates Drawing.new().
UI Builder Generates interactive menu. Programmatically creates ScreenGui, binds events, uses TweenService.
Main Loop Keeps systems synced. RunService.RenderStepped updates targets, ESP, FOV, and FPS.
Unload System Cleans up memory. Disconnects listeners, destroys GUIs, restores original metatable.

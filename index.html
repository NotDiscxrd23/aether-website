Features that change everything

Every system engineered for maximum efficiency and minimal footprint.

🎯 Silent Aim

Intercepts raycasts at the metatable level (`__namecall`). Zero recoil. Redirects weapon trajectories locally without touching your camera's CFrame.

👁️ Advanced ESP

3D Boxes, Skeletons, Tracers, and Health bars drawn natively using the `Drawing` API. Updates dynamically via RenderStepped loops.

📷 Camera Freeze

Locks your camera CFrame in place while your character continues to move. Uses a dedicated watchdog to prevent the game from resetting the camera type.

✨ Glassmorphism UI

A fully custom, draggable interface built entirely from Roblox Instances. Features tabs, sliders, dropdowns, keybind catchers, and TweenService animations.

🧠 Smart Target Caching

Intelligently caches valid targets every 0.1 seconds, filtering out dead players, teammates, and invalid models. Ensures low CPU usage and perfect target selection.

Under the hood

How the Lua architecture is structured. A breakdown of the script's internal modules.

Module Functionality Technical Implementation
Services & State Initializes core variables and configurations. Calls game:GetService() and builds a centralized Config table to store user preferences dynamically.
The Hook Redirects weapon fire toward targets. Uses getrawmetatable(game) to intercept __namecall. Filters specifically for Raycast calls originating from weapons.
ESP Engine Renders visual overlays over players. Converts 3D world positions to 2D screen coordinates using WorldToViewportPoint, then updates Drawing.new() objects every frame.
UI Builder Generates the interactive menu. Programmatically creates ScreenGui, ScrollingFrame, and binds events. Uses TweenService for smooth transitions.
Main Loop Keeps systems synchronized. A RunService.RenderStepped connection runs continuously to update target selection, ESP drawings, FOV circles, and FPS counters.
Unload System Cleans up memory when closed. Disconnects all event listeners, destroys GUI instances, removes Drawing objects, and restores the original metatable to prevent crashes.
